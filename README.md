# Swacanatase

Exploratory tooling for modeling a tube-shaped enzyme concept that positions
catalytic groups around carbon nanohoops/nanorings.

The current code focuses on the RCSB Chemical Component Dictionary non-canonical
amino acid BP5 (`3-(2,2'-BIPYRIDIN-5-YL)-L-ALANINE`) and first-pass armchair
`(M,M)` carbon scaffolds generated by the sibling `../tuber` project.

Implemented pieces include:

- BP5 CCD download and structured loading into Biotite `AtomArray` objects.
- BP5 bond-pair loading from CCD CIF.
- Conversion of the CCD BP5 bipyridine geometry into the active cis donor form
  by rigidly rotating the `C6` side around the `C3-C6` inter-ring bond.
- Construction of a square-planar Pd active-site model with appended `PD`,
  `CV1`, and `CV2` pseudo/virtual atoms.
- Armchair `(n,n)` nanoring scaffold generation through `tuber`.
- Central-band anchor selection for para-like and inter-benzene linker carbon
  pairs.
- Placement of `M/2` BP5/Pd sidechains around default `M = 18, 24, 30, 36`
  nanoring scaffolds.

## Setup

From this directory:

```bash
uv sync --extra dev
```

This project depends on `tuber` as an editable local path dependency:
`../tuber`.

## Local Data

`data/` is ignored by git. A working checkout needs local BP5 CCD files before
running tests or placement commands:

Download BP5 Chemical Component Dictionary files from RCSB:

```bash
uv run swacanatase-download-bp5 --overwrite
```

The command writes:

- `data/rcsb/BP5.cif`: CCD definition containing model and ideal coordinates
- `data/rcsb/BP5_ideal.sdf`: ideal-coordinate SDF from RCSB

The repository may also contain local ignored generated outputs under
`data/generated/` and reference notes/PDFs under `data/references/`.

## BP5 Loading And Active Site

Load the ideal CCD coordinates as a Biotite `AtomArray`:

```python
from pathlib import Path

from swacanatase import (
    build_bp5_palladium_active_site,
    describe_square_planar_geometry,
    load_bp5_atom_array,
)

bp5 = load_bp5_atom_array()
active_site = build_bp5_palladium_active_site(Path("data/rcsb/BP5.cif"))
geometry = describe_square_planar_geometry(active_site)

print(bp5.array_length())          # 31
print(active_site.array_length())  # 34: BP5 + PD/CV1/CV2
print(geometry.pd_n_bond_length)
```

By default the active-site builder uses ideal CCD coordinates, rotates BP5 into
the cis donor conformer, and appends:

- `PD`: palladium pseudo-atom
- `CV1`, `CV2`: virtual carbon positions for the two coupling carbons

Default distances are `PD-N = 2.018 Angstrom` and
`PD-CV = 2.020 Angstrom`.

## Armchair Nanohoop Scaffolds

Generate an armchair `(n,n)` carbon scaffold using `tuber`:

```bash
uv run swacanatase-generate-armchair --n 6 --units 1 --output data/generated/nanoring/armchair_6_6.cif
```

Or from Python:

```python
from swacanatase import generate_armchair_nanoring

ring = generate_armchair_nanoring(n=6, units=1)
print(ring.array_length())
```

Generate the current M=N nanoring series with 1.5 armchair units, giving `6M`
carbon atoms, and place `M/2` BP5 sidechains around the central inter-benzene
linker carbon pairs:

```bash
uv run swacanatase-generate-bp5-nanorings --m 18 24 30 36 --output-dir data/generated --overwrite
```

The command writes `data/generated/nanoring/nanoring_M*.cif` scaffold files and
`data/generated/theozyme/nanoring_M*_bp5.cif` complex files containing the placed
BP5 active-site model. In generated complexes, BP5/Pd sidechains use chain `A`
and the carbon scaffold uses chain `B`.

By default, `CV1` and `CV2` keep the ideal catalytic geometry and are rigid-fit
to minimize residuals against the selected adjacent scaffold carbons. Use
`--snap-virtual-carbons` only when exact virtual-carbon overlap is desired.

Useful options:

```bash
uv run swacanatase-generate-bp5-nanorings \
  --m 18 24 \
  --units 1.5 \
  --anchor-phase-offset 1 \
  --format cif \
  --output-dir data/generated \
  --overwrite
```

## Data Backup

Local data under `data/` is intentionally not tracked by git. Use S3 sync for
backup/restore once a private bucket exists:

```bash
export SWACANATASE_DATA_S3_URI=s3://your-bucket/swacanatase/data
scripts/sync-data-s3 upload --dry-run
scripts/sync-data-s3 upload
scripts/sync-data-s3 download
```

The sync script accepts an explicit URI instead of the environment variable:

```bash
scripts/sync-data-s3 upload s3://your-bucket/swacanatase/data
```

`--delete` is supported for pruning the destination, but run it with
`--dry-run` first.

## Tests

```bash
uv run --extra dev pytest
```

Tests are deterministic and do not perform live network access, but they expect
`data/rcsb/BP5.cif` to exist locally. Run the BP5 download command first in a
fresh checkout.
